# F-025 · SUPERSEDES the 'exact recovery' part of F-012 (reviewer3; Opus re-verified on real kit cases 0-2). The effective-mu matrix, 1.04 deg column angle, singular values and cond=1272.96 all reproduce, BUT they describe the ZERO-THICKNESS spectrum-weighted mean. Under beam hardening the local effective matrix changes with path length: cond falls to ~900-960 at 10 cm and ~750-800 at 25 cm, and the adipose/fibroglandular angle to 0.87-0.97 deg. cond=1273 is therefore an UPPER BOUND, not the operative conditioning. DECISIVE: on REAL AAPM kit images the linear effective-mu model is wrong by 7.8% (50 kVp) and 5.9% (80 kVp) relative on tissue pixels, and amplified by sigma_max(B^-1[:,:2]) = 343 this makes the sum_to_one estimator WORSE THAN PREDICTING ZERO: all-pixel RMSE 1.555 vs 0.447 for zero_prediction (tissue 1.823 vs 0.567); unconstrained 0.317 and simplex 0.379 also beat sum_to_one. My claim that 'exact recovery is possible in the noiseless challenge data' is FALSE in the image domain: the data are noiseless but the image-domain linear model is NOT the model that generated them (the real data are polychromatic + FBP). Exactness held only on synthetic data I generated with the same linear model I then inverted - an inverse crime I did not label as such.

## Statement

SUPERSEDES the 'exact recovery' part of F-012 (reviewer3; Opus re-verified on real kit cases 0-2). The effective-mu matrix, 1.04 deg column angle, singular values and cond=1272.96 all reproduce, BUT they describe the ZERO-THICKNESS spectrum-weighted mean. Under beam hardening the local effective matrix changes with path length: cond falls to ~900-960 at 10 cm and ~750-800 at 25 cm, and the adipose/fibroglandular angle to 0.87-0.97 deg. cond=1273 is therefore an UPPER BOUND, not the operative conditioning. DECISIVE: on REAL AAPM kit images the linear effective-mu model is wrong by 7.8% (50 kVp) and 5.9% (80 kVp) relative on tissue pixels, and amplified by sigma_max(B^-1[:,:2]) = 343 this makes the sum_to_one estimator WORSE THAN PREDICTING ZERO: all-pixel RMSE 1.555 vs 0.447 for zero_prediction (tissue 1.823 vs 0.567); unconstrained 0.317 and simplex 0.379 also beat sum_to_one. My claim that 'exact recovery is possible in the noiseless challenge data' is FALSE in the image domain: the data are noiseless but the image-domain linear model is NOT the model that generated them (the real data are polychromatic + FBP). Exactness held only on synthetic data I generated with the same linear model I then inverted - an inverse crime I did not label as such.

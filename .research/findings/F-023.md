# F-023 · SELF-CRITICISM: pre-registered prediction P3 was BADLY DESIGNED and its failure is my error, not a result about priors. P3 predicted that adding sum_to_one would cut tissue RMSE >5x versus B3-linear. It did not (0.468 vs 0.476, 1.02x) and the pre-registered STOP condition fired. But P3 was unfalsifiable-as-intended for two reasons I should have caught at pre-registration: (1) it compared a PENALTY-weighted soft constraint (prior_weight=1.0, a value never specified in the pre-registration and never tuned) against the HARD constraint whose >5x effect F-019 actually demonstrated - a soft penalty at an arbitrary weight is not the same intervention; (2) the B4 variant spread is 0.2162 while the supervised network floor is 0.037, i.e. 17% of the spread, so prior effects of the size F-019 predicts were partially masked. The correct conclusion is NOT 'sum_to_one fails to identify' (F-019 proves it does, exactly, as a hard constraint) but 'a unit-weight soft sum_to_one penalty does not recover the hard constraint's identifying power in this training setup'. Evidence: B4e/B4f, which impose sum-to-one ARCHITECTURALLY via softmax, collapsed to constant all-adipose maps on every seed - a hard constraint plus an unconstrained consistency objective gives a degenerate solution, which is itself consistent with F-018.

## Statement

SELF-CRITICISM: pre-registered prediction P3 was BADLY DESIGNED and its failure is my error, not a result about priors. P3 predicted that adding sum_to_one would cut tissue RMSE >5x versus B3-linear. It did not (0.468 vs 0.476, 1.02x) and the pre-registered STOP condition fired. But P3 was unfalsifiable-as-intended for two reasons I should have caught at pre-registration: (1) it compared a PENALTY-weighted soft constraint (prior_weight=1.0, a value never specified in the pre-registration and never tuned) against the HARD constraint whose >5x effect F-019 actually demonstrated - a soft penalty at an arbitrary weight is not the same intervention; (2) the B4 variant spread is 0.2162 while the supervised network floor is 0.037, i.e. 17% of the spread, so prior effects of the size F-019 predicts were partially masked. The correct conclusion is NOT 'sum_to_one fails to identify' (F-019 proves it does, exactly, as a hard constraint) but 'a unit-weight soft sum_to_one penalty does not recover the hard constraint's identifying power in this training setup'. Evidence: B4e/B4f, which impose sum-to-one ARCHITECTURALLY via softmax, collapsed to constant all-adipose maps on every seed - a hard constraint plus an unconstrained consistency objective gives a degenerate solution, which is itself consistent with F-018.

# F-019 · EXPERIMENT A part 2: which constraints actually remove the ambiguity. (a) NONNEGATIVITY alone is insufficient: for a boundary/band pixel (truth [0.55,0.25,0.004], sum 0.804) an exact-measurement decoy [0.735,0.073,0.006] with sum 0.814 is fully nonnegative, so it survives the constraint. Larger decoys do go negative, so nonnegativity bounds but does not eliminate the family. (b) EXACT SUM-TO-ONE does remove the pixelwise ambiguity: the perturbation must satisfy both mu_eff d = 0 and sum(d) = 0, which is 3 equations in 3 unknowns, and [mu;1] is full rank (singular values 3.697, 1.176, 0.0029). Note the linear null direction has sum = -0.0393 != 0, i.e. it necessarily changes total path length - that is exactly why the sum constraint bites. (c) BUT sum-to-one is FALSE for 35% air and ~5% band pixels (F-013), so the identifying constraint is valid on only ~60% of the image, and applying it elsewhere is a model error whose effect is amplified by cond=1273 (F-015/F-016). The identifiability of this problem is therefore REGIME-DEPENDENT, not global.

## Statement

EXPERIMENT A part 2: which constraints actually remove the ambiguity. (a) NONNEGATIVITY alone is insufficient: for a boundary/band pixel (truth [0.55,0.25,0.004], sum 0.804) an exact-measurement decoy [0.735,0.073,0.006] with sum 0.814 is fully nonnegative, so it survives the constraint. Larger decoys do go negative, so nonnegativity bounds but does not eliminate the family. (b) EXACT SUM-TO-ONE does remove the pixelwise ambiguity: the perturbation must satisfy both mu_eff d = 0 and sum(d) = 0, which is 3 equations in 3 unknowns, and [mu;1] is full rank (singular values 3.697, 1.176, 0.0029). Note the linear null direction has sum = -0.0393 != 0, i.e. it necessarily changes total path length - that is exactly why the sum constraint bites. (c) BUT sum-to-one is FALSE for 35% air and ~5% band pixels (F-013), so the identifying constraint is valid on only ~60% of the image, and applying it elsewhere is a model error whose effect is amplified by cond=1273 (F-015/F-016). The identifiability of this problem is therefore REGIME-DEPENDENT, not global.

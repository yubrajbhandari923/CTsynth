# F-015 · REFINES F-013 (boundary pixels are the hard case, not merely a partial-volume nuisance). In the two-regime AAPM partition, pixels whose three fractions sum strictly between 0 and 1 (~5% of the image) are mis-modelled by a sum-to-one estimator: the unit-sum row CONTRADICTS the measurement there, and that contradiction is amplified by the ~1273 conditioning, so the resulting error is far LARGER than the sum deficit (1 - sum) itself. Simplex projection only clips the result and does not fix the model error. Consequence for the benchmark: boundary-band error must be reported separately (it is, in the evaluation record), and an air/tissue decision rule is a MODELLING CHOICE, not a fact recoverable from the data - the implementation uses AIR_CUTOFF_PER_CM = 0.1 (half the smallest tissue mu from F-012), which is untested on real AAPM data.

## Statement

REFINES F-013 (boundary pixels are the hard case, not merely a partial-volume nuisance). In the two-regime AAPM partition, pixels whose three fractions sum strictly between 0 and 1 (~5% of the image) are mis-modelled by a sum-to-one estimator: the unit-sum row CONTRADICTS the measurement there, and that contradiction is amplified by the ~1273 conditioning, so the resulting error is far LARGER than the sum deficit (1 - sum) itself. Simplex projection only clips the result and does not fix the model error. Consequence for the benchmark: boundary-band error must be reported separately (it is, in the evaluation record), and an air/tissue decision rule is a MODELLING CHOICE, not a fact recoverable from the data - the implementation uses AIR_CUTOFF_PER_CM = 0.1 (half the smallest tissue mu from F-012), which is untested on real AAPM data.

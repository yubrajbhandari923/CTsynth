# F-038 · PROCESS: four HPC bundles (RUN-0019..RUN-0022) accidentally included the local .venv-xcist

## Statement

hpc.bundle.exclude was set before the XCIST venv existed and matched '.venv' but not '.venv-xcist'; I did not re-preview the bundle contents before later submissions. RUN-0019, RUN-0020, RUN-0021 and RUN-0022 each uploaded ~5580 extra files (~60 MB compressed per bundle, 4 bundles; local unpacked bundle dirs total ~1 GB under .research/hpc/bundles, gitignored) to /home/yb107/research-os/projects/CTsynth/code/EXP-011/RUN-0019..0021 and EXP-012/RUN-0022. No scientific result depends on those files (jobs ran from the separately built env, and run outputs were hash-verified), but it violates the intent of the bundle-exclude rule and consumes cluster home space (NFS home was 82% used). Fixed: exclude now '.venv*'; a source preview shows 139 files / 0.85 MB with no venv. Lesson: re-run the bundle-content preview before EVERY submission once new local directories exist.

## Limitations

Exact remote size not measured (hpc inspect shows no sizes). Remote copies not deleted: needs human approval.

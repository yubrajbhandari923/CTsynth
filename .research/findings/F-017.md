# F-017 · PROCESS (D-004 follow-up): when the provenance system itself writes into the repo during a run, a whole-tree git_dirty flag is ALWAYS true and therefore useless as a citability signal - it flagged RUN-0003/4/5 as non-citable purely because Research OS was logging the run. ctsynth.runmeta now records git_dirty_source (src/tests/configs only) alongside git_dirty; citability depends on the SOURCE being clean. Experiment outputs were also untracked (projects/*/results*/ gitignored) because writing results into a tracked directory dirties the tree as the run executes. RUN-0006 is the first run with git_dirty_source=False.

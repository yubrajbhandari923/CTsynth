- [awaiting review] F-021 PENG 2024 IS NOT A LABEL-FREE COMPARATOR. Loss L = lambda*||A[x1;x2] - [mu_H;mu_L]||^2 + L_GAN, image-domain on linear attenuation coefficients with a LINEAR 2x2 per-pixel matrix A from ROI means: no spectrum, no projector, no Poisson term. Because A is square and invertible the fidelity minimum is exactly the noisy direct inversion, so the GAN term supplies ALL the noise suppression (SD -91-97%). The discriminator requires an UNPAIRED reference set of clean material maps built by thresholding SECT/high-energy images from other patients, so the method carries a learned prior fitted to label-like data: it is 'unpaired-reference adversarial', not label-free. Like Hellwege it is 2-from-2 (determined, no sum-to-one row) and so says nothing about our 3-from-2 null space. Usable only as an unpaired-reference-prior baseline on a 2-material subproblem, and must be labelled as such. - [awaiting review] F-019 EXPERIMENT A part 2: which constraints actually remove the ambiguity. (a) NONNEGATIVITY alone is insufficient: for a boundary/band pixel (truth [0.55,0.25,0.004], sum 0.804) an exact-measurement decoy [0.735,0.073,0.006] with sum 0.814 is fully nonnegative, so it survives the constraint. Larger decoys do go negative, so nonnegativity bounds but does not eliminate the family. (b) EXACT SUM-TO-ONE does remove the pixelwise ambiguity: the perturbation must satisfy both mu_eff d = 0 and sum(d) = 0, which is 3 equations in 3 unknowns, and [mu;1] is full rank (singular values 3.697, 1.176, 0.0029). ## Active decisions

- D-006 (2026-10-11) The B3 'label-free physics-consistent U-Net' rung is REFRAMED from a reproduction target into a NEGATIVE CONTROL. Experiment A proves (machine precision, real polychromatic model) that measurement consistency alone has a continuum of exact global minima for 3-from-2, so B3 cannot be expected to recover materials and its purpose is to demonstrate this empirically and to reveal WHICH member of the ambiguous family the network's implicit priors select. Neither primary paper is a precedent: Hellwege is 2-from-2 determined with no regulariser, Peng is 2-from-2 with an unpaired-reference adversarial prior. No faithful reproduction of either will be attempted on the 3-material task: it would be a category error, and both papers' complete methods are in any case unverifiable (no code, unstated activation/bin count for Hellwege, supplement unavailable for Peng). The scientific question becomes: which added prior selects the true member, and does it do so for a physical reason or by accident?
- D-005 (2026-10-11) AAPM benchmark design is governed by two facts established in discovery: (1) the challenge data are NOISELESS and the forward model was shared with all participants, so this is an EXACT-RECOVERY problem (winning s1 RMSE 6.8e-7, i.e. ~1e-6 is reachable and is NOT a noise floor) - a denoising-style evaluation would be meaningless; (2) 3-material recovery from 2 spectral measurements is made well posed by a SUM-TO-ONE constraint on VOLUME FRACTIONS (2 spectral equations + 1 partition constraint = 3 equations, unique when the three (mu_low, mu_high) points are non-collinear), not by nonnegativity or priors. Therefore: the classical baseline uses volume fractions with an explicit simplex constraint; nonnegativity alone is insufficient; and our metric must match the published s1 = mean over cases of sqrt(||t-r||^2/(3n)) on dimensionless volume fractions.

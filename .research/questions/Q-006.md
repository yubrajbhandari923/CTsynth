# Q-006 · P02-Q6: Can a network recover physically meaningful material maps from spectral measurement consistency ALONE (no paired labels)? Prior analysis (F-014) says NO for the AAPM 2-measurement/3-material case: the null direction is invisible to the data, so a pure consistency loss is minimised by a one-parameter family containing the truth and infinitely many wrong maps. The scientific content is therefore WHICH added prior selects the truth, and whether it does so for physical reasons or by accident.

## Findings

- **F-018** EXPERIMENT A (deterministic, no training): a pure measurement-consistency loss CANNOT identify 3 material maps from 2 spectral measurements on the AAPM model, and this is not a linearisation artifact. Using the REAL polychromatic forward model and the official CC-BY spectra/mu tables, I solved for alternative material path-length vectors that reproduce BOTH kVp transmissions to machine precision: holding calcification at 0.05/0.06/0.08/0.10 cm and re-solving adipose+fibroglandular by Newton gives exact-measurement decoys with relative transmission error <= 1.8e-16 and ||dx|| up to 6.53 cm (e.g. truth [8.0,4.0,0.05] vs decoy [12.72,-0.51,0.10]). The decoy family is one-dimensional, as predicted by the 2x3 rank. Consequence: ANY label-free objective whose only signal is measurement consistency has a continuum of exact global minima; a network trained on it converges to whichever member its implicit priors (architecture, initialisation, amortisation) prefer, NOT to the truth. Reporting a low consistency loss as evidence of material accuracy is therefore invalid for this problem. (preliminary)
- **F-019** EXPERIMENT A part 2: which constraints actually remove the ambiguity. (a) NONNEGATIVITY alone is insufficient: for a boundary/band pixel (truth [0.55,0.25,0.004], sum 0.804) an exact-measurement decoy [0.735,0.073,0.006] with sum 0.814 is fully nonnegative, so it survives the constraint. Larger decoys do go negative, so nonnegativity bounds but does not eliminate the family. (b) EXACT SUM-TO-ONE does remove the pixelwise ambiguity: the perturbation must satisfy both mu_eff d = 0 and sum(d) = 0, which is 3 equations in 3 unknowns, and [mu;1] is full rank (singular values 3.697, 1.176, 0.0029). Note the linear null direction has sum = -0.0393 != 0, i.e. it necessarily changes total path length - that is exactly why the sum constraint bites. (c) BUT sum-to-one is FALSE for 35% air and ~5% band pixels (F-013), so the identifying constraint is valid on only ~60% of the image, and applying it elsewhere is a model error whose effect is amplified by cond=1273 (F-015/F-016). The identifiability of this problem is therefore REGIME-DEPENDENT, not global. (preliminary)
- **F-020** HELLWEGE 2026 IS NOT A PRECEDENT FOR OUR PROBLEM (full arXiv PDF text read). Their task is 2 basis materials (soft tissue, calcification) from 2 spectra: SQUARE and determined by counting, so pixelwise identifiability is automatic and never discussed in the paper. Our AAPM task is 3 materials from 2 spectra: underdetermined, and in their Eq. 6 objective L = (1/|D|)(1/M) sum_i [||p_LE - phat_LE||^2 + ||p_HE - phat_HE||^2] (unweighted MSE on log line integrals, no I0, no Poisson term, NO regulariser, no nonnegativity, no sum-to-one, no TV, no entropy, no softmax) our F-014 null direction would be EXACTLY FLAT. The paper reports no ablations at all; its gain over MBIR (VMI RMSE 5.83 vs 13.07 HU at 50 keV) comes from the network and training, not from the loss. The authors state the inverse crime explicitly (Sec 4.2: same polychromatic model generates and decodes) and run no mismatch experiment. Early stopping uses projection-domain validation loss with no ground truth, which is a genuinely label-free protocol worth copying. Unverified: energy-bin count, final activation, how 3+ AAPM tissue classes were merged into 2, whether data were noisy, and Table 1 mean-vs-median. (preliminary)
- **F-021** PENG 2024 IS NOT A LABEL-FREE COMPARATOR. Loss L = lambda*||A[x1;x2] - [mu_H;mu_L]||^2 + L_GAN, image-domain on linear attenuation coefficients with a LINEAR 2x2 per-pixel matrix A from ROI means: no spectrum, no projector, no Poisson term. Because A is square and invertible the fidelity minimum is exactly the noisy direct inversion, so the GAN term supplies ALL the noise suppression (SD -91-97%). The discriminator requires an UNPAIRED reference set of clean material maps built by thresholding SECT/high-energy images from other patients, so the method carries a learned prior fitted to label-like data: it is 'unpaired-reference adversarial', not label-free. Evaluation ground truth uses the same thresholding recipe, so the reference prior is in-distribution with the evaluation - a self-favouring protocol. Like Hellwege it is 2-from-2 (determined, no sum-to-one row) and so says nothing about our 3-from-2 null space. Usable only as an unpaired-reference-prior baseline on a 2-material subproblem, and must be labelled as such. Unverified: published lambda (supplement not obtained; 1e4/1e2 from arXiv v1 only), exact GAN loss form, hyperparameter protocol; no code released. (preliminary)

# EXP-020 · Label-free end-to-end demo: supervised vs physics-only vs physics+feasibility

## Hypothesis

Physics-only reproduces transmissions without recovering materials (F-014 null direction); gradient flow succeeds

## Motivation


## Method

projects/p05_aapm/milestone_a.py, three arms as three runs (parallel 1-GPU jobs), same data: first 32 frozen-train cases for training, first 8 frozen-val cases for selection/evaluation (test split untouched), U-Net depth 2 width 8 with SOFTPLUS output (nonnegativity by architecture, the same in all arms; a linear output made the physics forward overflow, RUN-0032), Adam lr 1e-3, seed 0, steps/batch fixed before running (3000 steps, batch 2). A supervised (label MSE; selection by val label MSE). B physics (projection MSE on 32 random view positions per step vs measured transmissions; NO labels in loss, selection or targets; selection by val projection loss on 32 fixed views). C physics_feas (B + sum<=1 hinge, weight 1.0: feasibility only, not an identifying prior). Evaluation on val after selection: s1, per-material RMSE, partition errors, full 256-view projection RMSE, null_dir_error_frac = sum|e.n| / sum||e|| (n = F-012 null direction; an isotropic 3-D error gives ~0.5).

## Expected outcome


## Success criteria

Gradient flow: all losses/grad norms finite for all arms. Reported SEPARATELY per arm: projection RMSE (T) and material errors (s1, per-material RMSE). Pre-registered expectation (F-014): arm B reaches low projection error without proportionally low material error, with null_dir_error_frac clearly above the isotropic 0.5 (>=0.8); arm A lowest material error; C does not fix the null direction by itself. Single seed, 8 val cases: descriptive only (Exp 7/9 add seeds and power analysis).

## Stop conditions

Nonfinite gradient or label leakage found in arms B/C (audit: truth appears only in evaluation).

## Synthesis S1 — 2026-10-13 (agent: claude-code)

- **What happened:** Three runs on identical data (first 32 frozen-train cases for training, first 8 frozen-val cases for selection and evaluation; test untouched), softplus U-Net depth 2 width 8, 3000 steps, seed 0. RUN-0034 supervised (34 s): s1 0.0294; RMSE adipose 0.0349 / fibro 0.0362 / calc 0.0103; full-view projection RMSE (T) 0.00258; null_dir_error_frac 0.84. RUN-0035 physics-only, no labels anywhere in loss/selection (705 s, 1.6 GB): s1 0.392; RMSE 0.498 / 0.463 / 0.010; projection RMSE 0.00429; null fraction 0.997; tissue mean |sum-1| 0.062. RUN-0036 physics + sum<=1 hinge (704 s): s1 0.504; RMSE 0.648 / 0.586 / 0.010; projection RMSE 0.00442; null fraction 0.992. All losses/grad norms finite in all arms (max grad norm 16.3 / 6.5 / 24.9). Figures: RUN-0035 figures.png shows the physics-only network predicting a spatially uniform disk (about half adipose, half fibroglandular, zero calcification) regardless of anatomy.
- **What worked:** Milestone A path runs end to end: image -> U-Net -> fractions -> fan-beam polychromatic forward -> projection loss -> backward -> step, with finite gradients, on GPU; labels enter only the supervised arm (audit: milestone_a.py passes truth to the training step only when arm=supervised).
- **What did not work:** Not a failure of the pipeline, but note the physics-only arm did NOT reach a lower projection error than the supervised arm (4.3e-3 vs 2.6e-3 RMSE in T): it was under-trained/optimisation-limited at 3000 steps on 32 cases, so 'matches the transmissions' is only approximately true here.
- **Interpretation:** Successful gradient flow is not successful recovery. Label-free projection consistency produced a collapsed, anatomically empty adipose/fibroglandular mixture (s1 13x worse than supervised) while its projection error was only 1.7x worse; 99.7% of its material error lies along the F-012 null direction (isotropic reference ~0.5). This matches the pre-registered expectation from F-014 (null direction invisible to the data) but is a single seed and 8 val cases, descriptive only. The sum<=1 hinge (feasibility only) did not help and worsened s1 (0.50): a weak feasibility constraint does not select the truth. Calcification RMSE 0.010 in all arms is NOT recovery evidence: calcification covers ~0.4% of pixels, and predicting zero scores about this value.
- **Limitations:** One seed; 32 training / 8 validation cases; short training; the supervised arm's own error is also 84% along the null direction; the physics arms' hyperparameters (lr, views per step) were not tuned; same-model data (no mismatch).
- **Unresolved:** Whether longer training drives physics-only projection error below supervised; seed spread (EXP-023 addresses with 3 seeds on the full split).
- **Recommended next:** Milestone A checkpoint; then EXP-021 classical baselines and EXP-022 supervised full-data U-Net.

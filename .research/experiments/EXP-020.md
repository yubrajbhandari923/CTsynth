## Method

projects/p05_aapm/milestone_a.py, three arms as three runs (parallel 1-GPU jobs), same data: first 32 frozen-train cases for training, first 8 frozen-val cases for selection/evaluation (test split untouched), U-Net depth 2 width 8 with SOFTPLUS output (nonnegativity by architecture, the same in all arms; a linear output made the physics forward overflow, RUN-0032), Adam lr 1e-3, seed 0, steps/batch fixed before running (3000 steps, batch 2).

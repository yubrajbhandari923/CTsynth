- **Interpretation:** Plumbing works (shapes, channel order, finite grads, checkpoint, figures) but the criterion is failed, so this is not a smoke pass. Fixes (engineering, decided before rerun): softplus output in all arms, 3000 steps, per-pixel-norm null metric. Findings: unconstrained outputs are incompatible with the polychromatic forward model; any physics arm needs a nonnegativity parameterisation or clamp.
- **Limitations:** Single case, train=val; no generalisation claim.
- **Recommended next:** Rerun as a second run of EXP-019 with the fixes.

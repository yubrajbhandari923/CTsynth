# EXP-024 · Occupancy-aware output parameterisations

## Hypothesis

Predicted-occupancy factorisation helps boundary; oracle occupancy is upper bound only

## Motivation


## Method

projects/p05_aapm/milestone_a.py --arm physics (label-free training, same data/recipe/steps as EXP-023: 800 train, 100 val, depth 4 width 32, lr 3e-4 warmup 300 clip 1, 6000 steps, batch 4, 32 views/step), 3 seeds per arm, differing ONLY in output parameterisation: (1) linear output with exp_clip=20 numerical guard (negative fractions allowed); (2) softplus nonnegative = EXP-023 runs RUN-0047/48/49, reused not rerun; (3) 3-channel softmax (sum=1 everywhere, wrong on air by construction); (4) softplus + soft two-regime partition penalty w*[(S-1)^2 on measured-tissue pixels + S^2 on measured-air pixels] with w in {1.6e-5, 1.6e-4} (w chosen by a scale rule fixed now: weighted penalty = 10% resp. 100% of the validation projection loss (9.6e-7) at the EXP-023 seed-0 solution, where the unweighted penalty is 6.0e-3; measured-air = both images < 0.1/cm, no truth); (5) predicted occupancy sigmoid x 3-way softmax (occ_softmax); (6) ORACLE: 3-way softmax x TRUE per-pixel sum S, labelled an upper-bound control, never a legitimate estimator. NOTE all 1000 cases share one support mask (EXP-031), so (6) injects a constant image and cannot test generalisation to new supports.

## Expected outcome


## Success criteria

Per arm and seed on 100 validation cases: s1, s2, boundary/interior RMSE, tissue |S-1|, air |S|, projection RMSE, null_dir_error_frac, collapse flag. Decision rule fixed now: an arm 'helps' only if its 3-seed mean s1 is below the EXP-023 mean (0.2956) by more than 2x the pooled seed range of the two arms; arms that merely reduce |S-1| without lowering s1 are reported as clipping errors, not information. Oracle row reported separately.

## Stop conditions

Oracle arm used anywhere as an estimator; labels in non-oracle training.

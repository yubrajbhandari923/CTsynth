## Synthesis S1 — 2026-10-14 (agent: claude-code)

- **What happened:** RUN-0053/0054/0055 (1 GPU each, 57 min): the frozen EXP-022 reference U-Net (RUN-0041, seed 0) refined per case by Adam on the projection loss (+ mu*||F-F0||^2), K up to 200, 100 validation cases. mu=0: s1 0.01842 (K=0) -> 0.01828 / 0.01815 / 0.01801 / 0.01784 / 0.01768 at K=10/25/50/100/200; boundary RMSE 0.01037 -> 0.00921; full-view projection RMSE 1.31e-3 -> 1.4e-4 (9x lower); paired per-case change in s1 at K=200: mean -0.00073, sd 0.00013, improved in 100/100 cases. mu=1e-3 is indistinguishable from mu=0 (s1 0.01768, projection 1.6e-4). mu=1e-2: see the run record (RUN-0055).
- **What worked:** Non-learned physics refinement uses the same verified forward; monotone, consistent in every case.
- **What did not work:** By the registered decision rule (gain > EXP-022 seed range 0.0024) refinement does NOT help: the best gain is 0.0007 (4%).
- **Interpretation:** Physics refinement fixes the part of the error the data can see and nothing else: projection error falls 9x while s1 improves only 4%, because the residual material error is ~84% along the F-012 null direction, to which the measurements are nearly blind. Consistent with EXP-023/032: more physics-consistency is not more material accuracy. The tiny but uniform gain (100% of cases) is real as a paired effect but small relative to seed-to-seed variability of the network (0.0024). This is an inspired baseline (not a reproduction of the AAPM winner JLRM, whose public code at github.com/GM0322/JLRM and training details were not run or verified here) and its published 6.8e-7 scale is far from anything we obtained; a learned unrolled variant was not run (not justified by this result).
- **Limitations:** Only seed 0's network refined; (K,mu) chosen on the validation cases themselves; Adam lr 0.005 and 32-view subsets fixed, not tuned; K=200 not converged (projection still falling); no test evaluation yet.
- **Unresolved:** Whether many more iterations with a learned regulariser (as in the winning method) reaches the null-direction component; out of scope here.

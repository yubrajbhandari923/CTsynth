# D-009 · D-M laptop/HPC bundle workflow

## Decision

Laptop<->HPC workflow: the laptop is authoritative, the cluster is a dumb execution worker, and transfer is manual. Implemented as 'ctsynth prepare|verify|export|import|report' (stdlib argparse, NO new dependency, ZERO network I/O - nothing in the package can contact a cluster). Research OS remains the single system of record: import registers via 'research run attach' rather than building a second tracker. Integrity rules enforced in code: prepare refuses a dirty src/tests/configs tree; verify checks every manifest hash, the config hash and commit EXISTENCE+UNAMBIGUITY (not ancestry, so old/diverged commits stay importable); import refuses duplicates via an idempotency marker and never overwrites a completed run; external checkpoints are recorded by hash without being copied. SLURM templates render every unset cluster field as a commented TODO instead of a guessed default, because a wrong partition produces a job that silently never runs.

## Reason

Verified end to end across two directories (RUN-0010) plus 32 frozen tests covering corrupted hashes, missing outputs, failed jobs, duplicate imports and old-commit traceability.

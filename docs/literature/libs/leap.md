- Fit for small differentiable 2D forward model: poor as a dependency. ## Verdict: USE AS TEST ORACLE ONLY (optional, never imported by the package)
Rationale: MIT, accurate matched footprint projectors make it a good independent reference to validate our own 2D torch projector's line integrals and adjointness (dot-product test) in an opt-in test marked skip-if-not-installed. Not worth being a dependency: no wheel on PyPI/macOS arm64, source build, torch forced by setup.py, 3D/global-state API, inactive since 2024-12 on releases. Caveat: an oracle test requires someone to build it once on the M-series Mac; if that build fails, drop the oracle and use analytic phantoms (disc/ellipse Radon transforms) instead.
